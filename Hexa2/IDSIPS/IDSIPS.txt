HTML, CSS, JS를 활용해서 IDS/IPS 프로그램 제작하려고 한다.

1. 서버 자원 관리 시스템
1-1. 전체 서버 자원 사용률을 보여주는 화면
1-2. IP별 서버 자원 사용률을 보여주는 화면

2. IP 차단 및 권한 부여 시스템
2-1. 서버 자원을 과도하게 사용하거나 의심스러운 활동을 하는 IP를 수동으로 차단하는 장치
2-2. 서버 자원 관리 시스템에 의거해 서버 자원을 과도하게(10% 이상) 사용하는 IP를 자동으로 차단하고 경보를 울리는 장치
2-3. 방화벽 시스템에 의거해 포트 스캔을 시도하는 IP를 자동으로 차단하고 경보를 울리는 장치
2-4. 관리자가 일반 사용자에 대해 인허가하는 장치

3. 로그 수집 및 자동 저장 시스템
3-1. 시스템 전체 로그 수집 및 별도 파일 시스템에 자동 저장하는 시스템
3-2. 의심스러운 활동을 하는 로그를 따로 수집해 자동 저장하는 시스템

4. 방화벽 시스템
4-1. 권한 또는 핵심 파일(자동 저당된 로그 파일) 변경 시 해당 접속을 자동으로 종료시키고 경보를 울리는 장치
4-2. HTTP를 HTTPS로 강제 리다이렉트하는 장치, SSL 인증서 자동 갱신 확인 장치
4-3. 서버 운영에 불필요한 포트를 자동으로 닫고 포트 스캐닝을 탐지하는 장치
4-4. 관리자는 IP 차단당하지 않는 장치

4-2. HTTP를 HTTPS로 강제 리다이렉트 (80 포트 설정)
사용자가 http://로 접속해도 자동으로 https://로 보내주는 설정입니다.

Nginx
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    return 301 https://$host$request_uri; # 모든 요청을 HTTPS로 전달
}
